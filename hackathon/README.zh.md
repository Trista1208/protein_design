# 战役计划：从头设计 Kemp 消除酶（DBSSE × Perlin Bio）

[English](README.md) · [中文](README.zh.md)

黑客松：**Design a Catalyst.** 巴塞尔，2026 年 11 月。主讲：Lucas Merlicek（Perlin Bio）。邮箱：hello@perlin.bio

这是 **活性位点 motif 脚手架酶设计**，不是结合蛋白设计，也不是去改已发表的 Kemp 酶。

**先做这个（不用 GPU）：** [basics/](basics/) — 长度/序列相似度硬门 + TSA 与底物 + 已发表 Kemp FASTA。运行 `python3 hackathon/basics/scripts/validate_design.py --self-test`。

## 目标

- **反应：** 5-硝基苯并异噁唑的 Kemp 消除。催化 **碱** 抽走碳上的氢 → 异噁唑环打开。可用 **氢键供体** 稳定逐渐形成的氧负离子。
- **起点：** 全新设计。不要从 KE07 / KE70 / HG3 等已发表 Kemp 折叠出发。
- **必须保住（催化契约）：** Asp 做碱 + Gln 做氢键供体，相对配体的几何要对。幻灯片第 5 页在 DFT 过渡态和 TSA 上都用了这一对残基。
- **必须改掉：** 整个骨架。新序列、新折叠。
- **打分用的配体：** **6-硝基苯并三唑**（过渡态类似物 TSA）。DFT 过渡态是化学真相；Boltz-2 实际看到的是 TSA。
- **实验 / 成功线：** 官方四项打分（见下）；**至少 5 条序列进湿实验**，与分数无关。计算机过关 ≠ 有活性。历史上 de novo Kemp 酶往往要进化后才快。

## 工具栈

| 阶段 | 默认 | 没有 RFD4 GPU 时 |
|---|---|---|
| 骨架 | RFD4-Proteina 酶 / motif scaffolding（`recycle_strategy=medium/midpeak`） | RFdiffusion3 / RFdiffusion |
| 条件 | 带配体 + Asp/Gln 的 annotated CIF 或 YAML（`C_CRD` / `C_IDX` / `C_HB`） | contig + 活性位点残基指定 |
| 序列 | RFD4 inverse folding **并且** LigandMPNN / ProteinMPNN，**固定 Asp+Gln** | LigandMPNN / CARBonAra |
| Oracle | **Boltz-2 蛋白+TSA 共折叠**（黑客松打分器） | AF3 / Chai-1 / Protenix-v2 作交叉检查 |
| 多目标 | iPDE、几何、碱包埋、一致性的 Pareto，不要合成一个“总分”就完事 | 几何过关后再用 MoMST 做序列可表达性 |
| 多样性 | Foldseek / TM：彼此之间，以及相对已发表酶 | 同左 |

不要用 Ptarmigan 这类无结构小分子模型。产品是蛋白质催化剂。

## 条件契约

- **可改（M_edit）：** 除催化残基身份外的整条设计链。
- **死守（M_prot）：** Asp（碱）、Gln（氢键）的身份，以及它们相对 TSA 的几何。脚手架后 motif 骨架 RMSD 目标 ≤ 1 Å。
- **可松弛：** 口袋第一、二壳层堆积；不要改催化残基身份。
- **配体：** 生成和打分都用 TSA 6-硝基苯并三唑。不要对着产物 3-氰基-4-硝基苯酚去优化。
- **直接淘汰：**
  - 长度 **> 260 aa**
  - 与已发表酶序列一致性 **> 70%**
  - 骨架相对已发表结构 **TM-score > 0.7**
  - 无配对 Cys（除非你有意做二硫键）
  - 催化碱暴露在溶剂中（包埋 / pKa 会挂）

先做一个 annotated CIF：TSA 坐标 + Asp + Gln + 可扩展骨架（先瞄准 **90–180 aa**；只有口袋需要桶状结构时再接近 250）。

## 采样计划（算力很紧）

主办方不会给你几十万条设计。要用 **少量高质量骨架**，而不是一团没聚类的库。

1. **Motif 库（数小时）：** 2–4 种 Asp–Gln–TSA 摆放（不同进攻角度、供体对准氧负离子）。骨架生成前先丢掉碰撞和明显不催化的几何。
2. **脚手架（GPU 第 1 天）：** 每个 motif 约 50–200 条骨架。RFD4 `num_replicates` 保持克制；有 oracle 环境再用酶/motif `metrics_tags`，否则 `'~metrics'`，本地用 Boltz-2 打分。
3. **反向折叠：** 每条过关骨架 4–8 条序列；**始终固定 Asp+Gln**。
4. **Boltz-2 初筛：** 先 1 个 seed。配体位置不自信的丢掉。
5. **一致性：** 短名单上跑满 **5 个 seed**（与官方打分一致）。
6. **可选 search：** 早期看口袋氢键 / 配体接触；后期看 iPDE / pLDDT。不要把预算全砸在 search 上。
7. **部分扩散：** 对最好的复合物用 0.25–0.35，收紧口袋，但不要漂回已发表折叠。

## 评估漏斗

先硬门，再排序。几何没过之前，不要把 iPDE 和包埋平均成一个数。

1. **长度与新颖性：** ≤260 aa；一致性 ≤70%；相对已发表 Kemp / PDB 的 TM ≤0.7。
2. **Motif 几何（G1）：** Asp 羧基对准被抽氢的碳；Gln 氢键对准氧负离子类似位置；距离/键角/二面角对照 Perlin 的理想进攻几何。配体无碰撞。
3. **范围（G3）：** 催化残基仍是 Asp+Gln；TSA 仍在设计口袋里（不是另一个乱结合位点）。
4. **iPDE：** 配体 token 被自信放置（越低越好）。TSA 漂在表面或飞掉 → 淘汰。
5. **催化碱包埋：** 碱周围 **12 Å** 内的 Cα 数量；碱不应暴露在溶剂中。
6. **可设计性：** 蛋白 pLDDT 高；口袋 PAE / 蛋白–配体误差低。无配体再折叠时 scRMSD 大约 < 2 Å。
7. **一致性：** 5 个 Boltz-2 seed 复现姿态和指标（预组织的代理指标）。
8. **可表达性：** 无未配对 Cys、没有巨大疏水斑、pI 适合大肠杆菌（若这是表达宿主）。
9. **多样性：** Foldseek 聚类；每类留 1–2 条。
10. **实验室短名单 5+：** 不要五条近重复。Pareto：最好几何、最好一致性、最好包埋、一条更短骨架、一条更极性口袋。

官方分数在问什么：

| 指标 | 它在问 |
|---|---|
| iPDE | 配体有没有被自信地放进口袋？ |
| Geometry | 碱 + 氢键 + 配体朝向能不能干活？ |
| Catalytic base burial | 碱是否埋得够深，pKa 才有用？ |
| Consistency | 多次共折叠能不能复现结构？ |

## 预期失败模式

- **口袋很漂亮，酶是死的：** 结合了 TSA，但 Asp 几何不能抽氢。
- **碱暴露：** iPDE 很好，羧酸根被水溶剂化 → pKa 不对。
- **抄了 KE/HG 折叠：** TM 或序列一致性超标 → 即使分数好看也出局。
- **Seed 彩票：** 一次 Boltz-2 很美，另外四次很烂 → 一致性失败。
- **配体幻觉：** 表面结合却给出低 iPDE。
- **范围泄漏：** 反向折叠时 Asp/Gln 被改掉或漂走。
- **聚集 / 不表达：** 为包硝基芳环把疏水核做过头。
- **过拟合 TSA：** 6-硝基苯并三唑 ≠ 真实 5-硝基苯并异噁唑过渡态。分数只是过滤器，不是 k_cat 证明。

现实预期：多数 in silico 过关序列在裂解液里没有活性。真正的交付是 **5 个实验名额**；历史上 Kemp 酶变快靠的是定向进化（若后续允许）。

## 第一轮湿实验

- **数量：** 至少 **5** 条（保底）。若名额变多，从其他聚类加，不要加复制品。
- **DNA：** 大肠杆菌密码子优化；His 标签；避免不想要的糖基化序列。
- **酶活：** 经典 Kemp 消除（酚类产物的紫外吸收）。对照：无酶、缓冲液、催化碱敲除（Asp→Asn 或 Ala）、以及主办方若提供的阳性对照。
- **Go / no-go：** 高于本底且敲除后活性消失 → 在该骨架上迭代。五条全是本底 → 换 motif 摆放，而不是只改 MPNN 温度。

## 有数据之后怎么迭代

- 完全不结合：口袋放松 / 加第二个供体 / 换 motif 构象。
- 结合但无活性：对照 DFT 过渡态查几何；旋转碱；把它埋深一点。
- 表达失败：骨架固定，用 MoMST 风格的 `hydrophobic,surface_expose,plddt` 改序列。
- 有微弱命中：对该复合物做部分扩散；**不要**跳到已发表 Kemp 骨架（TM 规则）。
