# Protein design skills

Canonical location for this pack. Each folder is a portable Agent Skill (`SKILL.md` + optional references). Copy `skills/` into any GitHub repo; adapters like `.cursor/skills` are optional.

| When the user asks to… | Read |
|---|---|
| Propose / critique / run a full campaign | `protein-design-campaign/SKILL.md` |
| Generate with RFD4-Proteina | `rfd4-proteina/SKILL.md` |
| Text-guided local 3D editing (PROTEAN) | `protean-editing/SKILL.md` |
| Multi-objective test-time scaling (MoMST) | `momst-multiobjective/SKILL.md` |
| Filter before wet lab | `protein-design-filters/SKILL.md` |
| ProteinMPNN / AF / ESMFold / Boltz / RFdiffusion | `inverse-folding-classics/SKILL.md` |
| Disordered targets / structure-free ligand screens | `structure-free-design/SKILL.md` |

Repo-level usage: see `../README.md` and `../AGENTS.md`.
