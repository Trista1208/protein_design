# Agent instructions

This repository is a portable protein-design skill pack. It is not tied to a single IDE.

For the DBSSE × Perlin Kemp eliminase hackathon, follow `hackathon/README.md` (English) or `hackathon/README.zh.md` (Chinese) before sampling.

When the user asks to design, edit, filter, or campaign on proteins:

1. Read `skills/README.md`.
2. Load the matching `skills/<name>/SKILL.md` (see the table there).
3. Follow linked files in that skill folder (`campaign-template.md`, `yaml-recipes.md`, `examples.md`) only as needed.
4. Prefer live tool docs over memorized CLI flags.
5. Ask if the target, preserve/change contract, or assay is missing.
6. Refuse dual-use requests whose primary intent is toxin, pathogen, or weapon enhancement.

Do not require `.cursor/` or any vendor-specific skill path. `skills/` is canonical.
